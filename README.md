# Aadvika S - Portfolio Website

A premium personal portfolio website showcasing my journey in AI & Data Science, featuring modern design, smooth animations, and comprehensive project showcases.

## 🚀 Features

- **Dark Theme Design**: Modern black background with orange/red/yellow accent colors
- **Custom Animations**: Smooth hover effects, scroll animations, and custom cursor
- **Fully Responsive**: Optimized for all devices and screen sizes
- **Project Showcase**: Detailed project cards with problem/solution/impact structure
- **Experience Section**: Professional experience including apprenticeship and cultural exchange
- **Skills Display**: Categorized technical and soft skills with animated cards
- **Contact Integration**: Direct links to email, phone, GitHub, and LinkedIn

## 🛠️ Tech Stack

- **Frontend**: React 18 with Vite
- **Styling**: Custom CSS with CSS variables and gradients
- **Animations**: Framer Motion for smooth interactions
- **Icons**: Lucide React for premium iconography
- **Deployment**: Ready for GitHub Pages deployment

## 📱 Sections

1. **Hero**: Introduction with key statistics
2. **About Me**: Professional narrative and highlights
3. **Skills**: Technical and soft skills showcase
4. **Projects**: 4+ featured projects with detailed descriptions
5. **Experience**: Professional roles and cultural exchange program
6. **Certifications**: 8+ certifications from IBM, LinkedIn, UC Davis, etc.
7. **Education**: B.Tech at Kumaraguru College of Technology
8. **Interests**: Personal interests with icons
9. **Contact**: Comprehensive contact information

## 🎨 Design Highlights

- **Color Scheme**: Black base with orange (#ff6b35), red (#ff3333), and yellow (#ffcc00) accents
- **Typography**: Clean sans-serif with strong hierarchy
- **Micro-interactions**: Custom cursor, hover states, and smooth transitions
- **Layout**: Grid-based responsive design with consistent spacing
- **Visual Effects**: Gradient text, animated cards, and scroll-based animations

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or npm installed

### Installation
```bash
# Clone the repository
git clone https://github.com/aadviiika/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Development
```bash
# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📱 Deployment

This portfolio is optimized for GitHub Pages deployment:

1. Push to `main` branch
2. Enable GitHub Pages in repository settings
3. Select source as `gh-pages` (if using gh-pages branch) or `main` with `/` root folder
